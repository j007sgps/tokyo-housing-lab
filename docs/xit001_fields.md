樣本：立川市（13202）2021Q1〜2026Q1，共 21 季 × 2 種價格 = 42 個檔案、3535 筆
（取引價格 01：2152 筆，成約價格 02：1383 筆；其中中古マンション等 1682 筆）。
2026Q2 以後回 404（尚未公開）。

重現方式：
```bash
uv run python scripts/profile_raw.py data/raw/xit001_*.json --merge [--type 中古マンション等]
```

## 整體結構

- 回應是 `{"status": "OK", "data": [...]}`，每筆 29 個欄位，**所有值都是字串**
- 沒有值的欄位是空字串 `""`，不是 `null`，也不會整個 key 消失
- 數值欄位沒有千分位逗號，全部是半形數字
- `Period`（例：`"2024年第1四半期"`）和請求的年／季**全部一致**（0 筆不符）
- `PriceCategory` 和請求的價格種類**全部一致**：01 → `不動産取引価格情報`、02 → `成約価格情報`
- **沒有任何一筆交易的唯一 ID**；完全相同內容的中古マンション有 15 組重複（可能是同一棟樓的不同戶，無法分辨）

## 中古マンション等的欄位

| 欄位 | 觀察 |
|---|---|
| TradePrice | 全部是整數日圓 |
| Area | 全部是 5 的倍數（15〜115），應該已經被四捨五入過；有 1 筆是 `1100`（整棟辦公大樓，FloorPlan=`オープンフロア`、Purpose=`事務所`） |
| UnitPrice / PricePerUnit | **全部是空的**，㎡ 單價要用 TradePrice ÷ Area 自己算 |
| BuildingYear | `"YYYY年"`（1966〜2025）；空值 36 筆、`戦前` 1 筆；沒有建築年晚於交易年的情況 |
| FloorPlan | 全形（`３ＬＤＫ`、`２ＬＤＫ＋Ｓ`）；另外有 `オープンフロア`、`スタジオ`；空值 16 筆 |
| Structure | 全形（`ＲＣ`、`ＳＲＣ`）；有組合值（`ＲＣ、鉄骨造`）；空值 39 筆 |
| Purpose | **02 全部是空的**；01 為 住宅 695、その他 72、事務所 4、店舗 4、空 28 |
| Use | 02 全部是空的 |
| Renovation | 01：未改装 488、改装済み 228、空 87；02：改装済み 24、其餘空 |
| CoverageRatio / FloorAreaRatio | 02 全部是空的；01 有 7 筆空的 |
| CityPlanning | 空值 77 筆（大多在 02） |
| Remarks | 只有 01 的 `調停・競売等` 5 筆 |

## ㎡ 單價（TradePrice ÷ Area）分布

最低 4.5 萬、P1 8 萬、中位數 48 萬、P99 140 萬、最高 210 萬（日圓／㎡）。
低於 15 萬的約 100 筆，大多是 1966〜1971 年的舊公寓，看起來是真實的成交，不是資料錯誤。

## 其他注意事項

- **最新一季可能還不完整**：2026Q1 的 01 中古マンション只有 21 筆，以往每季大約 30〜50 筆
- 宅地(土地) 的 `UnitPrice` 是每 ㎡ 單價，`PricePerUnit` 是每坪單價
