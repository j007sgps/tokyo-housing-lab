# XIT001 回應欄位觀察（步驟 2）

樣本：立川市（13202）2024Q1，取引價格（01）95 筆、成約價格（02）50 筆。
重現方式：`uv run python scripts/profile_raw.py data/raw/*.json [--type 中古マンション等]`

> 只看了一季。下面寫「沒看到」的東西，不代表其他季也不會出現。

## 整體結構

- 回應是 `{"status": "OK", "data": [...]}`，每筆 29 個欄位，**所有值都是字串**
- 沒有值的欄位是空字串 `""`，不是 `null`，也不會整個 key 消失
- 數值欄位沒有千分位逗號，全部是半形數字
- `Period` 是 `"2024年第1四半期"`，和請求參數一致

## Type 的實際值

| Type | 01 | 02 |
|---|---|---|
| 中古マンション等 | 46 | 35 |
| 宅地(土地と建物) | 34 | 15 |
| 宅地(土地) | 15 | 0 |

M1 要的是 `中古マンション等`。注意名稱裡有「等」：01 有 4 筆 `Purpose=その他`、1 筆 `Purpose=事務所`。

## 中古マンション等會用到的欄位

| 欄位 | 範例 | 觀察 |
|---|---|---|
| TradePrice | `"11000000"` | 全部是整數日圓，都是 10 萬的倍數 |
| Area | `"40"` | 整數 ㎡，**全部是 5 的倍數**（範圍 15〜110），應該已經被四捨五入過 |
| UnitPrice / PricePerUnit | `""` | 中古マンション**全部是空的**，只有土地才有值，所以 ㎡ 單價要自己用 TradePrice ÷ Area 算 |
| BuildingYear | `"2022年"` | 格式都是「西元年＋年」；01 有 1 筆空值。這一季沒看到「戦前」 |
| FloorPlan | `"３ＬＤＫ"`、`"２ＬＤＫ＋Ｓ"` | 全形英數字 |
| Structure | `"ＲＣ"`、`"ＳＲＣ"` | 全形 |
| Renovation | `"未改装"`、`"改装済み"` | 只有 01 有值 |
| Purpose / Use | `"住宅"` 等 | 只有 01 有值 |
| CoverageRatio / FloorAreaRatio | `"80"`、`"400"` | 單位是 %，**02 全部是空的** |
| CityPlanning | `"商業地域"` | 02 有 3 筆空值 |
| DistrictName / DistrictCode | `"錦町"` / `"132020110"` | 都有值 |

## 01 和 02 的差別

成約價格（02）的資料比較少：Region、Renovation、Purpose、Use、CoverageRatio、FloorAreaRatio、Remarks 全部是空的。

## 其他觀察

- 宅地(土地と建物) 有 1 筆 `TotalFloorArea = "9999"`，很可能代表「上限值」或是特殊的代碼，和中古マンション無關，但清理規則要把它標記出來
- 宅地(土地) 的 `UnitPrice` 是每 ㎡ 單價，`PricePerUnit` 是每坪單價（約為 3.3 倍）
- **這一季沒有看到**「以上」「戦前」「〜」這類非數字的值
